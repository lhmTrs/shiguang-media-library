# 项目资产：原图文件操作和头像裁切建议

图片文件操作仅限本机 Mac 桌面。客户端不提交文件路径。使用当前人物的图片绑定编号和版本，服务端按素材根目录和登记时的图片内容摘要核验原文件；复制的是可粘贴到支持文件粘贴的应用的原文件引用，HEIC 保留原扩展名和内容。

- `GET /api/project-assets/projects/:id/desktop-capabilities` 返回 `version`、`maxSelection`、`clipboard`、`revealMany`。
- 项目下的 `POST /images/clipboard`、`POST /images/reveal/preview`、`POST /images/reveal` 使用 `{requestId, mode, items:[{bindingId,bindingRevision}]}`。人物卡片用 `defaults`，每项须是该人物当前卡片代表图；同一人物的参考图用 `references`，可跨造型。每次最多 50 项。
- 访达执行另带核对回执的 `previewToken`，生成新的 `requestId`，保持原来选择与顺序。核对不会打开访达，回执中的 `folderCount` 可决定是否再提示。执行成功回执仅说明系统已收到打开请求。
- 操作处理中按同项目的 `GET /desktop-actions/:requestId` 查询；遇到回复丢失或结果未知，用原编号查询，不自动新建请求重做。被跳过的文件和已处理的文件分列，结果不返回路径。

`GET /api/project-assets/bindings/:id/head-box` 可带 `?bindingRevision=...`，只返回建议，不能写入资产。识别基于已核验的私有图片副本；HEIC 使用与预览相同的兼容转换。返回 `found`、`not_found`、`unsupported`、`busy` 或 `error`；已发现绑定或原图变化时返回 409 / `IMAGE_BINDING_STALE`。成功返回预览方向宽高、左上为原点的归一化人脸框，以及 3:4 卡片裁切建议 `crop:{x,y,zoom}`。相近多脸或识别失败保留手工裁切。

普通资产 PUT 沿用同一次版本校验。首次采用新默认图时，已知未调过的图片可以同一次保存使用及时取得的建议；失败仍可保存默认图。打开裁切面板和主动“重新框到头部”只改变草稿，用户保存后才生效。旧记录的 `crop_source=null` 不自动覆盖；`untouched` 表示已知未调过，`manual` 表示手动裁切（数值回到默认也须提交此状态），`auto` 表示主动采纳或首次采用的自动建议。人工历史和曾作为人物卡片默认图均由服务端维护，不随撤销回退。撤销需同时核对和恢复坐标与来源。
